# 🧠 טריוויה משפחתית

משחק טריוויה בעברית לרעות (11), יואב (8) ועידו (5.5). React + Vite + Tailwind.

## הפעלה

```bash
npm install
npm run dev
```

ואז לפתוח את http://localhost:5173 (גם מטאבלט באותה רשת – הכתובת מופיעה בטרמינל).

## מה יש במשחק

- **בחירת שחקן**: שלושה פרופילים מוכנים עם האיורים של הילדים, ואפשרות להוסיף שחקנים (כולל אורחים זמניים) ולערוך פרופילים.
- **שלוש רמות קושי**: קל (3 תשובות עם אימוג'י גדולים והקראה אוטומטית), בינוני ומאתגר.
- **סבב של 10 שאלות**: שאלות שעוד לא נראו מקבלות עדיפות, וסדר התשובות מתערבב בכל סבב.
- **משוב מיידי**: קונפטי וצליל לתשובה נכונה, ורעידה עדינה עם סימון התשובה הנכונה לתשובה שגויה.
- **"הידעת?"**: חלון עם עובדה מעניינת אחרי כל שאלה.
- **כוכבים ומדבקות**: 10 כוכבים לכל תשובה נכונה, ועוד 5 כבונוס מהתשובה השלישית ברצף. יש 16 מדבקות לאסוף בחדר הפרסים.
- **הקראה בעברית** (`he-IL`) דרך Web Speech API. אם אין במכשיר קול עברי, תוצג הודעה.
- כל ההתקדמות נשמרת ב-`localStorage`.

## מבנה

```
src/
  App.jsx                 ניווט בין המסכים
  components/             מסכים ורכיבים (Game, QuestionCard, FactModal, Summary, StickerBook...)
  hooks/                  useLocalStorage, usePlayers, useSpeech
  data/questions.js       מאגר השאלות (68 שאלות: easy / medium / hard)
  data/stickers.js        הגדרות המדבקות ותנאי הפתיחה
  utils/                  לוגיקת סבב, צלילים (Web Audio) וקונפטי
public/avatars/           האיורים של הילדים
```

כדי להוסיף שאלות, מוסיפים אובייקט למערך המתאים ב-`src/data/questions.js`.
